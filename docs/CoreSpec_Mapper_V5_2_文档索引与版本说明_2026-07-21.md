## 2. V5.2 相对 V5.1 的关键变化

- 新增 `adaptive_v5` 与 `validated_v3` 两条隔离执行路线。
- 用批准人工掩膜和冻结项目配方恢复 NC-1 历史结果。
- 新增逐矿物 IoU、Precision、Recall 和面积差回归门。
- 接入 GeoCore M1-2 适配器，并显式报告模型注册表、Manifest 或权重缺失。
- 新增最小掩膜覆盖率、内部填充率、轮廓/裂缝风险和人工批准门。
- 桌面端由七步更新为八步，新增独立“阈值试算”和“运行”步骤。
- 新增阈值 JSON 导出、拒绝瀑布、结构化告警、非递增 ETA 和多倍率结果查看。
- 新增孤立可选 ENVI 头文件的分级处理。
- 非发布级结果不再显示为无条件绿色完成。

## 4. 文档适用边界

2026-07-20 的 V5.0/V5.1 文档保留为历史记录，不删除、不覆盖。若旧材料与本套 V5.2 文档冲突，以 2026-07-21 版为当前软件基线；历史实测报告仍可用于追溯通用自适应引擎的早期验证。

所有质量等级与 `publishable` 都是工程发布状态。任何“矿物准确率”“资源量”“矿化强度”结论必须另有独立地质真值和解释流程支持。
