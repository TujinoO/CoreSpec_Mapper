# CoreSpec Mapper V5.3 稳定版用户使用指南

- 指南版本：1.0
- 软件版本：V5.3.0 Stable
- 日期：2026-07-21
- 适用对象：高光谱实验、岩心编录、矿物填图和成果质检人员

> 推荐工作方式：先完成输入与掩膜检查，再审查矿物和标准谱，随后接受或调整阈值试算，最后运行全景识别。不要跳过掩膜人工批准和标准谱确认。

## 1. 安装与启动

### 1.1 系统要求

- Windows 10/11 64 位；
- 建议 16 GB 以上内存，长岩心或多矿物项目建议 32 GB；
- 建议至少保留输入数据体积 3 至 5 倍的可用磁盘空间；
- 显示分辨率建议 1920 × 1080，最低窗口尺寸 1120 × 720；
- 自动掩膜需要与主立方体对应的 RGB 影像；
- 无需另装 Python、Conda、PySide6 或模型依赖。

### 1.2 标准安装

1. 双击 `CoreSpec_Mapper_V5.3.0_Stable_Setup.exe`。
2. 阅读版本信息并选择安装目录；默认安装到当前用户的应用程序目录。
3. 保持“创建桌面快捷方式”和“创建开始菜单项”选中。
4. 完成安装后，从桌面或开始菜单启动 `CoreSpec Mapper V5.3`。
5. 首次启动在标题栏确认版本为 `CoreSpec Mapper V5.3`。

安装包包含桌面程序、内置光谱数据库、矿物 Catalog、智能掩膜模型及运行库。不要把安装目录中的数据库或模型文件单独移动。

### 1.3 升级与卸载

安装 V5.3 Stable 前不需要删除项目数据。安装程序只替换应用文件，不删除历史成果。卸载可使用 Windows“已安装的应用”或开始菜单中的卸载项；项目配置和用户输出目录不会随应用卸载而删除。

## 2. 开始前的数据准备

### 2.1 必需文件

- 主分析 ENVI 立方体：`.dat` 或 `.img`；
- 同名或可定位的 `.hdr`；
- 正确的波长列表和波长单位；
- 反射率数据应已经完成基础辐射/反射率校正；
- 自动掩膜模式还需要同批次 RGB 影像。

### 2.2 可选文件

- 已配准的 NIR/VNIR 或 SWIR 伴随影像；
- 与主立方体同网格的外部 ENVI 掩膜；
- 项目配置 JSON；
- 同网格、人工复核的高可信历史分类，用于项目级校准（需在配置中启用）。

### 2.3 数据检查建议

在进入应用前确认：主数据行列方向正确、没有错误转置；波长单调；无效值和饱和值有明确编码；RGB 与主数据覆盖同一岩心；输出盘有足够空间。伴随影像没有配准时只用于审计，不能期待软件自动融合。

## 3. 九步工作流总览

| 步骤 | 页面 | 需要完成的工作 | 进入下一步前的检查 |
|---:|---|---|---|
| 1 | 项目 | 设置项目名、说明和输出根目录 | 目录可写，不与输入混用 |
| 2 | 数据 | 选择主立方体与伴随影像 | 文件可读、尺寸与波长合理 |
| 3 | 掩膜 | 自动生成或加载外部掩膜 | 预览、质量指标和人工批准完成 |
| 4 | 矿物 | 选择目标矿物 | 支持级别与参考谱数量可接受 |
| 5 | 标准谱 | 审查实际入选谱 | 曲线、来源确认并勾选 |
| 6 | 模式 | 选择默认查看档，必要时展开高级设置 | 常规项目保持自动建议 |
| 7 | 阈值试算 | 复核三档阈值与风险 | 状态 resolved，修改后已重算 |
| 8 | 运行 | 检查三项准备状态并开始 | 数据、掩膜、标准谱/阈值均通过 |
| 9 | 结果 | 查看三档预览、质量与日志 | 质量门、条带指标和发布状态明确 |

## 4. 第 1 步：项目

1. 在“项目名称”填写钻孔、批次或研究区名称。软件会对文件名做安全处理。
2. 在“项目说明”记录钻孔、深度段、仪器或实验批次，可留空。
3. 在“输出根目录”选择专用成果目录。

每次运行创建独立 `run_id`，不会覆盖原始数据或历史运行。建议按“项目/日期/版本”管理输出根目录，不要把输出写入输入影像目录。

工具栏“打开配置”和“保存配置”可复用项目设置。加载旧配置后，V5.3 会保留未知的科学覆盖字段，并把应用版本写为 5.3.0。

## 5. 第 2 步：数据

### 5.1 选择主立方体

在“主分析立方体”选择 `.dat`、`.img` 或对应 ENVI 文件。应用会立即读取并在下方表格显示：角色、尺寸、波长范围、数据物理和状态。

“波段域”通常保持“自动判断”。只有 ENVI 头信息不充分且你明确知道传感器类型时，才手动选择 SWIR、NIR/VNIR 或 TIR。

“数据物理”必须与数据真实含义一致。反射率识别不得把辐亮度误选为反射率。

### 5.2 SG 平滑复选框

若输入已经使用兼容参数完成 SG 平滑，勾选“输入已经完成光谱 SG 平滑”。勾选后方框中会显示蓝色勾号，运行配置记录 `input_is_smoothed=true` 并跳过重复平滑。

如果不确定，保持未选中，让系统按当前配置执行平滑。

### 5.3 自动发现伴随影像

“自动发现同目录 RGB / NIR / SWIR”默认选中。选择主立方体后，应用会按同目录和文件名批次发现伴随文件，并立即更新表格。取消勾选后可手动指定。

自动掩膜需要 RGB。没有 RGB 时应改用外部掩膜，或先生成与主数据对应的 RGB。

## 6. 第 3 步：掩膜

### 6.1 自动材料掩膜

1. 选择“自动材料掩膜”。
2. 确认数据页已经选择 RGB。
3. 按需要设置最小连通域、边缘保护像元、内部填充率门槛和最小覆盖率；常规项目建议保留默认值。
4. 点击“生成/刷新掩膜预览”。
5. 等待审计完成；应用会停留在掩膜页并显示预览和指标。

自动模式固定使用应用内置智能岩心前景模型。模型缺失或 RGB 无效时会明确报错，不会切换到未经确认的其他算法。

### 6.2 外部 ENVI 掩膜

1. 选择“外部 ENVI 掩膜”。
2. 选择与主立方体行列一致的掩膜文件。
3. 文件读取后立即显示二值预览、尺寸、前景像元和覆盖比例。
4. 文件变更后点击“刷新外部掩膜预览”。

非零且有限的像元视为前景。外部掩膜必须与主立方体同网格；尺寸不一致时不要继续运行。

### 6.3 缩放与详细查看

掩膜预览支持“适应窗口、50%、100%、200%”。

- 适应窗口：快速检查整体覆盖；
- 50%：检查长条幅的整体连续性；
- 100%：按原始像素检查局部边缘；
- 200%：检查细裂缝、标签、托盘轮廓和漏提；
- 放大后使用水平/垂直滚动条平移。

### 6.4 人工批准

检查岩心主体是否完整、托盘和标签是否误入、裂缝网络是否被误当作材料、边缘是否明显漏提。完成后勾选人工批准，填写审核人/批次和可选备注。

更换掩膜来源或文件会自动取消批准，必须重新核对。方框显示蓝色勾号才表示批准已记录。

## 7. 第 4 步：矿物

矿物树一级为矿物族，二级为具体矿物。每个矿物显示支持级别、关键波段和可用参考谱数量。

- 已验证：可作为稳定版生产目标；
- 实验级：证据链可运行，但需项目验证；
- 不支持/禁用：当前传感器、数据物理或参考谱不满足要求。

父级复选框可批量选择同组矿物。建议从默认七个已验证 SWIR 目标开始，不要仅为“结果丰富”选入传感器不可观测的矿物。

修改矿物选择会清空标准谱确认和既有阈值试算，需要重新审计。

## 8. 第 5 步：标准谱

进入本页时应用执行项目审计并加载本项目实际入选的标准谱。

1. 使用“目标矿物”下拉框查看全部或单个矿物。
2. 图中每条曲线对应一条真实入选参考谱，不是平均或合并谱。
3. 右侧列表显示谱名、来源和可用评分。
4. 点击右侧任一条目，图中对应曲线会加粗并显示点标记。
5. 颜色和线型用于区分曲线；相似参考谱可能局部重合，这是正常现象。
6. 核对完成后勾选“我已核对本项目入选的标准光谱曲线与来源”。

如果某矿物列表为空，应返回矿物页取消选择，或检查传感器波段、数据物理和内置资源，不要跳过确认。

## 9. 第 6 步：模式

“默认结果”决定结果页首先显示哪个档位，不改变系统固定生成三档成果的事实。

- 平衡：推荐的日常解释基线；
- 严格：用于高可信复核和优先取样；
- 敏感：用于找漏和矿化边界检查。

### 9.1 高级自动设置

“高级自动设置”默认关闭。选中后标题前显示蓝色勾号，并展开 SG 窗口/阶数、分层样本块、块行数、执行块行数、每矿物最大参考谱数和伪影边缘宽度。

只有了解算法含义并准备重新做全景回归时才修改。点击“恢复自动建议”可回到稳定版默认值。高级值启用后会写入配置，不会只改变界面。

## 10. 第 7 步：阈值试算

进入该页会自动试算严格、平衡、敏感三档。表格按矿物组和档位显示：

- 列分位；
- 绝对 SAM 角度；
- 样本候选像元数；
- 矿物特征可通过像元数；
- resolved、warning 或 blocked 状态。

稳定版策略是“前段 SAM 尽量宽松，后段 SFF、诊断特征、相似矿物竞争和条带终检严格”。因此三档的最终差异不只来自 SAM 角度。

### 10.1 调整阈值

如需人工微调，只能在界面给出的 Catalog 安全范围内编辑列分位和绝对 SAM。修改后页面标记为待重算，运行按钮禁用。点击“应用调整并重新试算”，等待全场景验证完成。

不要通过统一放宽阈值解决某矿物为零。先看“特征可通过”是否为零：若 SAM 有候选但诊断特征为零，根因是波段/谱形/数据质量或矿物特征不成立。

## 11. 第 8 步：运行

运行页显示三项准备状态：

1. 数据可用；
2. 掩膜已核对；
3. 标准谱和阈值已确认。

三项均通过且没有未重算的阈值修改时，“开始完整识别”按钮可用。运行期间：

- 进度条显示整体阶段；
- 日志显示当前处理内容；
- “已用”显示实测时间；
- “剩余”优先使用后端 ETA，后端返回无效 0 时自动改用观测进度估算；
- 初始样本不足时显示“估算中”，不会误显示一直 `00:00`；
- 可点击停止按钮，程序会等待安全检查点并避免发布不完整成果。

长任务中不要强制结束进程或关闭输出盘。窗口关闭请求会先触发安全取消。

## 12. 第 9 步：结果

结果页可切换中文预览名称，并支持适应窗口、50%、100%、200% 缩放。建议依次检查：

1. 严格、平衡、敏感三档总体差异；
2. 各矿物空间分布与岩性/蚀变规律；
3. 粘土矿物是否出现跨组重叠；
4. 是否仍有多个岩心段严格对齐的窄纵条；
5. 材料掩膜、固定列风险和 Al-OH 亚型预览；
6. 质量等级、警告和 `publishable` 状态。

点击“打开输出目录”进入本次独立运行目录。B/Warning 并不必然不可发布；必须结合 `publishable` 和具体警告解释。若出现 `REPEATED_NARROW_COLUMN_RESIDUAL`，说明最终仍存在可剔除条带，成果不可发布。

## 13. 输出目录说明

| 路径/文件 | 用途 |
|---|---|
| `config.resolved.json` | 实际运行配置和覆盖值 |
| `audit.json` | 输入、传感器、掩膜、标准谱和风险审计 |
| `capability/` | 能力卡、材料掩膜和矿物可观测性 |
| `library_ensemble/` | 实际入选标准谱及选择/拒绝记录 |
| `groups/<group>/` | 各组 SAM、SFF、特征、三档分类和拒绝原因 |
| `thresholds.json` | 候选范围、试算目标和最终阈值 |
| `previews/` | 中文三档、矿物组、掩膜、条带和亚型预览 |
| `quality/` | 质量指标、警告、发布门和报告 |
| `run_manifest.json` | 输入/资源哈希、耗时和完整输出清单 |

ENVI 分类应与其 `.hdr` 一起复制。对外移交建议同时包含 `run_manifest.json`、`thresholds.json`、质量报告和必要预览，以便复核。

## 14. 常见问题与排查

### 14.1 复选框有响应但看不到勾号

V5.3 Stable 已对普通复选框和可勾选高级设置叠加高对比蓝色勾号。若仍不可见，确认启动的是新版安装目录中的应用，并在“关于/标题栏”确认 V5.3；不要使用旧 V5.2 快捷方式。

### 14.2 自动掩膜按钮不可用或生成失败

检查是否正在运行其他任务、数据页是否选择 RGB、RGB 文件是否可读、主立方体是否选择、至少一个矿物是否选中。模型资源损坏时重新安装，不要手工复制单个权重文件。

### 14.3 掩膜预览太小

切换到 100% 或 200%，使用滚动条检查局部。适应窗口只用于总体覆盖检查。

### 14.4 选择三条白云石标准谱但只像一条

近似参考谱可能重合。查看“当前显示 3 条实际入选参考谱”，并点击右侧三条记录逐一高亮；颜色、线型和点标记会改变。数据不会被合并或删除。

### 14.5 方解石、白云石或蒙脱石为零

先查阈值页的候选数与特征可通过数，再查看拒绝原因。候选非零而特征为零说明诊断门不通过，不应无依据放宽阈值。确认波长覆盖、数据物理、参考谱和预处理后再决定是否调整 Catalog 或补充项目真值。

### 14.6 三档差异太小

检查是否有下游固定门或项目 QDA 把三档共同截断，查看各档候选、特征通过和最终计数。V5.3 已将三档解析为独立连续证据门；如仍接近，可能是场景证据本身集中，不应人为制造差异。

### 14.7 仍看到整齐纵向条带

查看质量报告中的重复窄列、主导重复走廊和可剔除像元。若指标非零，成果不得发布。若指标为零但视觉可疑，核对该结构是否仅出现在一个连续岩心段、是否跨走廊两侧延伸；保留下来的结构可能是裂隙、脉体或真实纵向矿化，需地质人员复核。

### 14.8 剩余时间显示“估算中”

任务初期缺少稳定速率时属于正常。获得有效进度点后会显示非零估算；后端中途返回 0 会被忽略。到任务接近 100% 时显示 `00:00` 正常。

### 14.9 质量为 B/Warning

展开警告。缺少 FWHM、缺少独立真值等科学限制可能保留 B/Warning，但若 `publishable=true` 且没有阻断发布门，工程成果可进入人工解释。质量等级不能当作矿物学准确率。

## 15. 推荐验收清单

运行前：

- 主立方体和 ENVI 头可读；
- 波长、数据物理和 SG 状态正确；
- 自动模式 RGB 可用，或外部掩膜同网格；
- 目标矿物与传感器能力匹配。

运行门：

- 掩膜预览已在 100%/200% 检查并批准；
- 标准谱数量、来源和曲线已确认；
- 阈值试算为 resolved；
- 修改后的阈值已经重新试算；
- 三项运行准备状态均通过。

发布前：

- 严格 ⊆ 平衡 ⊆ 敏感；
- 粘土跨组重复像元为 0；
- 重复窄列、主导重复走廊和可剔除条带像元为 0；
- `publishable=true`；
- Manifest、阈值、质量报告和 ENVI 头完整；
- 地质人员已复核异常纵向、斜向和裂隙状结构；
- 对外精度表述与独立真值水平一致。

## 16. 获得支持时应提供的信息

遇到问题时请提供：软件版本、项目配置、`audit.json`、`thresholds.json`、`run_manifest.json`、质量报告、相关预览和发生问题的操作步骤。不要只发送截图或单个分类 `.dat`；缺少头文件、阈值和审计记录时很难判断是输入、矿物特征、阈值还是空间伪影问题。
