## 2. 验收问题拆分

本次按以下顺序隔离问题：

1. 固定 SWIR 输入，排除数据版本变化。
2. 对比 V5.1 自动掩膜、V5.2 光谱回退和历史人工掩膜，先确认前景提取问题。
3. 冻结批准人工掩膜，避免掩膜误差污染分类算法评价。
4. 使用历史参考谱与平衡/敏感配方执行 `validated_v3`。
5. 逐矿物、逐档位与历史结果做像元级回归。
6. 检查拒绝瀑布、输出完整性、质量等级和可发布状态。

这一路径把“掩膜是否正确”“软件是否恢复历史算法”“自适应阈值是否可跨项目推广”分为三个不同问题。

### 5.3 指标解释

对每个矿物，历史分类为 reference，V5.2 为 candidate：

- Precision = 交集像元 / V5.2 该矿物像元；
- Recall = 交集像元 / 历史该矿物像元；
- IoU = 交集像元 / 并集像元；
- 面积差 = 两者像元数差相对 reference 的比例。

14 项均为 1.000，表示逐像元等价，不只是总面积相同。

## 6. 拒绝瀑布与方法核对

`rejection_waterfall.json` 按碳酸盐、硫酸盐和黏土组记录候选、证据拒绝、深度/分类拒绝、空间清理和最终各矿物数量。它用于确认结果数量变化发生在哪一层，并防止只看最终彩色图而无法追踪阈值影响。

本次冻结路线不重新运行 V5 自适应阈值搜索；阈值和参考谱来自历史验证配方。这是为了验证软件执行与历史基准等价。`adaptive_v5` 的跨钻孔可靠性应在独立真值数据上另行验收。
