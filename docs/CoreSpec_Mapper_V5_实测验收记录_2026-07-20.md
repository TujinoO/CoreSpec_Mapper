# CoreSpec Mapper V5 实测验收记录（2026-07-20）

## 1. 验收结论

本轮四个实测运行均已端到端完成，输出可重新打开、三档结果严格嵌套、掩膜编码一致，且没有矿物像元落到材料掩膜外。两组原始分辨率运行作为正式验收主证据；两组融合低分辨率运行只作为快速回归和界面联调证据。

当前结论为：**工程链路通过，阈值修复回归通过，地质应用有条件通过；但没有独立真值，不能写成矿物学准确率验收通过。** 主要限制有三：

1. 没有像元级或点位级矿物真值。PPT 人工解释和 ZKH3 编录只能作为定性或弱标签，不能计算准确率、召回率或混淆矩阵。
2. `v5_calibration` 已修复“同一候选掩膜下偏爱更宽 absolute SAM 阈值”的目标函数偏置，并恢复噪声相关吸收深度下限。四个 Final 运行中 absolute 上边界命中从历史基线的 60/60 降到 0/60；52/60 选择安全下边界，其余 8/60 选择中间值，说明偏置修复已实际进入输出。
3. ZKH3 原始数据仍依赖自动掩膜回退，最终材料掩膜有 263 个分量并触发 `MASK_HIGHLY_FRAGMENTED`；正式地质解释前仍应人工复核或提供同网格掩膜。

Final 原始运行显示结果并非固定列式伪影，但不同矿物的空间可信度差异明显：ZKH3 石膏和 3DSSZ 方解石的平衡档具有较高邻域支持；ZKH3 白云石、伊利石及部分方解石仍偏碎；蒙脱石和高岭石四个 Final 运行均为零检出，既不能证明缺失，也不能在无真值时直接判定漏检。

## 3. 指标定义

- “掩膜占比”是该矿物像元数除以最终材料掩膜像元数，不是除以整幅矩形影像。
- “8 邻域支持”是具有至少一个同类 8 邻域像元的检出像元比例；零检出记为“—”。
- 连通分量采用严格 8 连通。
- “≤4 px 小斑点像元”是落入不大于 4 像元连通分量的检出像元比例。它用于比较碎斑风险，不等同于地质学斑块大小阈值。
- 列密度为每列矿物像元数除以该列材料掩膜像元数。表中中位数与内置 QA 一致，包含整幅栅格的零材料列；完整 JSON 另给出了仅材料列中位数和 P95。
- 这些指标只评价内部一致性、空间聚集和伪影风险，不评价矿物学真值准确性。

## 8. PPT 与 ZKH3 编录弱标签对照

### 8.1 PPT 定性形态

PPT 人工结果体现的主要规律是团块、脉状、裂隙和岩性边界控制，而不是随机椒盐或固定列。原始预览中的方解石、石膏和部分伊利石主要落在岩心内部及破碎/岩性变化段，没有出现贯穿多盒的固定列；这一点定性通过。但 ZKH3 方解石、白云石、硬石膏和伊利石的小分量比例较高，仍不能称为“完全消除椒盐”。

本轮请求输出只覆盖方解石、白云石、硬石膏、石膏、伊利石、蒙脱石和高岭石。PPT 中的绿泥石、绿帘石、铁氧化物及其他人工类别没有作为本轮输出目标，不能用本轮零/非零结果评价这些类别。PPT 也不是与当前 ENVI 网格配准的真值掩膜。

### 8.2 ZKH3 134/137/139 钙质段

编录中 134、137、139 回次含钙质层段，只能作为碳酸盐弱标签。当前 SWIR 头文件只有 `x start=0`、`y start=0` 和占位像元尺寸，没有影像行—回次—深度映射；目录内也没有可验证的映射侧车。预览可分出 9 个主要岩心盒行区，数量与 132–140 相符，但自上而下方向、每盒内部起止方向和缺失/重叠关系均未编码，139 还存在编录端点错误。因此不能做正式行级或深度级命中率。

## 10. 最终发布门与后续真值验收

当前版本可以作为“矿物光谱证据制图与人工复核”试用版交付，但在以下条件完成前，不应写成“V5 矿物学准确率验收通过”：

1. 为 ZKH3 提供人工确认的同网格材料掩膜，或逐盒确认自动掩膜；为 3DSSZ 复核现有掩膜的 159 个分量。
2. 建立 ZKH3 行—盒—回次—深度—方向映射后，再评价 134、137、139 钙质段。
3. 至少选取一批 XRD、Raman、薄片或点光谱样点，形成独立真值；在此之前只报告“光谱证据”和空间一致性。
4. 对 PPT 明确出现、但本轮未输出或零检出的矿物类别单独设计验收：高岭石/地开石、蒙脱石、绿泥石、绿帘石和 Fe-oxide 族。
5. 继续关注 Final 中 52/60 个 absolute 选择落在安全下边界的现象；有真值后再优化 Catalog 边界和代理目标权重。
6. 桌面端在用户先执行 Audit 再 Run 的路径下，单独确认 `audit_snapshot_reused=true`；本轮 CLI 运行均为自行建立快照。

## 11. 复算方法

脚本只依赖 Python 标准库、NumPy 和项目 ENVI 模块：

```powershell
$env:PYTHONPATH='src'
python scripts/analyze_v5_validation.py `
  validation_runs/V5_Final_Raw_Validation/3dssz_raw_v5_final `
  validation_runs/V5_Final_Raw_Validation/zkh3_raw_v5_final `
  validation_runs/V5_Final_Validation/3dssz_lowres_v5_final2 `
  validation_runs/V5_Final_Validation/zkh3_lowres_v5_final2 `
  --output validation_runs/V5_final_validation_analysis_2026-07-20.json
```

JSON 包含每个矿物三档像元数、掩膜占比、8 邻域支持、连通分量、小斑点、列密度、阈值候选、耗时、掩膜质量、全部 Classification ENVI 清单和预览清单，可在修复后运行目录上原样复用。
